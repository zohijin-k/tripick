# 원스토어 등록 문구 (복붙용)

## 앱 이름
TRIPICK (트리픽)

## 한줄설명 (100자 이내)
직접 걸어서 검증하는 전주 여행 코스 — GPS 완주 데이터로 만드는 진짜 랭킹

## 상품 설명 (3,000자 이내)

🥾 TRIPICK은 리뷰가 아니라 '실제로 걸은 기록'으로 여행 코스를 검증하는 참여형 관광 플랫폼입니다.

별점은 좋은데 가보면 실망스러운 곳, 다들 한 번쯤 경험해보셨죠?
TRIPICK에서는 사용자가 코스를 실제로 걸으며 GPS로 자동 체크인하고,
완주율·만족도·수행자 수가 쌓여 신뢰할 수 있는 코스 랭킹이 만들어집니다.

■ 주요 기능

• 검증된 코스 랭킹 — 광고나 리뷰 조작 없이, GPS로 검증된 실제 수행 데이터만 반영
• GPS 자동 체크인 — 코스 지점 50m 이내 도착하면 자동으로 방문 기록
• 스마트 코스 만들기 — 여행 스타일·시간·이동 방식만 고르면 나만의 전주 코스 완성 (한국관광공사 TourAPI 기반)
• 완주 후 별점 리뷰 — 완주한 사람의 리뷰가 더 크게 반영되는 공정한 평가
• 지금 전주는 — 진행 중인 전주 축제·행사를 한눈에
• 체험 모드 — 전주에 가기 전에도 코스 수행 과정을 미리 체험

■ 전주에서 시작합니다

한옥마을에 몰리는 관광객, 그 너머의 전주를 아시나요?
TRIPICK은 객리단길·서학동 예술마을·남부시장·전주천 같은
숨은 코스에 가산점을 주어, 전주의 더 많은 골목이 발견되도록 설계했습니다.

지금 첫 수행자가 되어 전주를 걸어보세요.

■ 이용 안내
• 위치 권한: 코스 수행 중 자동 체크인과 주변 코스 추천에 사용됩니다 (앱 사용 중에만)
• 별도 회원가입 없이 바로 이용할 수 있습니다
• 관광지 데이터: 한국관광공사 TourAPI
